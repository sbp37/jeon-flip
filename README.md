# 전 뒤집기

모바일 웹 1탭 타이밍 미니게임. 손님 주문이 랜덤으로 들어오면, 전의 앞면이 노릇노릇해질 때 뒤집고 뒷면까지 노릇하게 익혀 완성한다. 60초 안에 최대한 많은 주문을 소화하는 게임.

## 실행

정적 파일만으로 동작. 로컬에서 보려면:

```bash
python3 -m http.server 8000
# http://localhost:8000
```

## 규칙

- 주문이 들어오면 반죽이 자동으로 부어지고 서서히 익는다
- **앞면**: 노릇해지면(초록 구간) 탭 → 뒤집기 성공 (+40점)
- **뒷면**: 다시 노릇해지면 탭 → 완성, 접시로 서빙 (+100점)
- 게이지 가운데 **황금 존**에 정확히 맞추면 완벽 판정 (뒤집기 +80 / 완성 +160)
- 너무 빠름 → 덜 익음 (실패), 너무 늦음 → 탐 (실패), 콤보 초기화
- 완성할수록 불이 세져서(불꽃 커지고) 전이 더 빨리 익는다
- 완성한 전은 접시에 쌓인다

## 전 종류

시작 화면에서 고른 전이 **대표 메뉴**가 되어 주문의 45%를 차지. 나머지는 랜덤.

| 종류 | 특성 |
|---|---|
| 부추전 | 기본. 익는 속도 보통, 판정 넓음 |
| 김치전 | 색 변화가 헷갈림. '지금이야!' 힌트 없음 |
| 해물전 | 익는 속도 느림, 성공 구간 좁음 |

## 팁

- 백그라운드로 가면 자동 일시정지 (전이 타지 않음)
- 우측 상단 버튼으로 사운드 on/off (설정 저장됨)

사운드는 WebAudio로 합성(지글지글/뒤집기/성공·실패/완벽). 첫 탭 이후 재생됨.
