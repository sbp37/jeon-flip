# 전 뒤집기

모바일 웹 전집 요리 타이쿤. 손님 주문을 확인한 뒤 기름을 두르고, 반죽 양을 맞추고, 주문에 맞는 재료를 골라 양면을 노릇하게 굽는다. 60초 동안 손님의 인내심을 지키며 최대한 높은 매출 점수를 만드는 게임. 장사가 바빠질수록 주문판이 가려져 주문을 기억해야 한다.

## 실행

정적 파일만으로 동작. 로컬에서 보려면:

```bash
python3 -m http.server 8000
# http://localhost:8000
```

## 조리 과정

한 주문은 다섯 단계로 진행된다.

1. **기름**: 팬 위 기름병을 잡고 어느 방향이든 반 바퀴 돌린다. 1.4초 안에 손으로 두르면 `+10`. 하단 `기름!` 버튼은 자동 두르기(보너스 없음)로 키보드·간편 조작 대안이다
2. **반죽**: 버튼을 누르고 있다가 게이지가 초록·황금 구간에 왔을 때 뗀다
3. **재료**: 주문을 떠올려 부추·김치·해물 중 올바른 재료를 선택한다. 가려진 주문을 맞히면 `+15`
4. **굽기**: 앞면과 뒷면을 각각 노릇한 구간에서 뒤집는다. 뒷면이 완성되면 자동으로 손님께 나간다

반죽 품질과 완성 시점의 남은 인내심이 높을수록 팁이 커진다. 잘못된 재료를 고르면 콤보·피버가 초기화되고 준비 품질이 30 낮아지며 손님 인내심이 2.5초 감소한 뒤 주문이 다시 공개된다. 인내심이 바닥나 손님이 떠나면 최대 100점을 잃고 콤보와 피버가 초기화된다.

## 규칙

- 시작 화면에서 선택한 대표 메뉴가 주문에 더 자주 등장한다
- **앞면**: 노릇해지면(초록 구간) 탭 → 뒤집기 성공 (기본 +40점)
- **뒷면**: 다시 노릇해지면 탭 → 완성, 접시로 서빙 (기본 +100점)
- 게이지 가운데 **황금 존**에 정확히 맞추면 완벽 판정 (뒤집기 기본 +80 / 완성 기본 +160)
- 2·4·6콤보부터 점수 배수가 `x1.2`·`x1.5`·`x2`로 상승한다
- 완벽 판정 3연속이면 5초간 **피버 타임**: 점수 `x2`, 조리 속도 15% 상승
- 너무 빠르면 덜 익음으로 `-1초`, 너무 늦어 타면 `-3초`; 콤보와 피버가 초기화된다
- 시간이 줄수록 장사가 바빠져 조리 속도가 오르고 판정 구간이 좁아지며 주문판이 일찍 가려진다
- 마지막 10초는 마감 러시로 점수 `x1.5`, 틱 소리와 3·2·1 카운트다운이 적용된다
- 결과 화면 별은 완성 3장·6장·9장 기준. 완벽 플레이 기준 60초에 약 11장
- 완성할수록 불이 세지고 완성한 전은 접시에 쌓인다

## 장사 단계

| 남은 시간 | 단계 | 변화 |
|---|---|---|
| 60~41초 | 준비 영업 | 기본 속도와 판정, 주문판 항상 공개 |
| 40~21초 | 손님 증가 | 조리 속도 상승, 판정 소폭 축소, 재료 단계부터 주문판 가려짐 |
| 20~11초 | 주문 폭주 | 조리 속도 추가 상승, 판정 축소, 점수 `x1.2`, 반죽 단계부터 주문판 가려짐 |
| 10~0초 | 마감 러시 | 가장 빠른 조리, 점수 `x1.5`, 마감 연출 |

## 전 종류

시작 화면에서 고른 전이 **대표 메뉴**가 되어 주문의 45%를 차지. 나머지는 랜덤.

| 종류 | 특성 |
|---|---|
| 부추전 | 기본. 익는 속도 보통, 판정 넓음 |
| 김치전 | 익는 속도가 빠르고 판정 구간이 짧음 |
| 해물전 | 익는 속도 느림, 성공 구간 좁음 |

## 팁

- 화면의 큰 동작 버튼은 터치·마우스뿐 아니라 키보드의 `Enter`/`Space`로도 조작할 수 있다
- 기름 단계에서는 팬 위 기름병을 반 바퀴 돌린다. 중간에 손을 떼도 진행률이 유지된다
- 팬을 드래그하기 어렵다면 하단 `기름!` 버튼으로 기름 단계를 완료할 수 있다
- 반죽 단계에서는 버튼을 누르고 있다가 원하는 양에서 떼며, 재료 단계에서는 세 메뉴 중 주문과 같은 재료를 고른다
- 결과 화면의 `다른 전 도전하기`는 다음 대표 메뉴로 바로 새 게임을 시작한다
- 좌측 상단 일시정지 메뉴에서 계속하기, 현재 점수 종료, 재시작, 대표 메뉴 이동을 선택할 수 있다
- 파괴적인 메뉴 동작은 한 번 더 확인하며 `Escape`로 일시정지/복귀할 수 있다
- 백그라운드로 가면 게임 시간과 전환 타이머가 함께 자동 일시정지된다 (전이 타지 않음)
- 우측 상단 버튼으로 사운드 on/off (설정 저장됨)
- 최고 점수는 브라우저에 저장되어 시작·결과 화면에 표시된다
- 기기의 모션 감소 설정과 화면 확대를 지원한다

사운드는 WebAudio로 합성(지글지글/뒤집기/성공·실패/완벽). 시작 버튼을 누른 뒤 재생된다.

기존 전·팬 이미지와 같은 따뜻한 수채화 톤으로 다음 SVG 에셋을 사용한다.

- `batter-pool.svg`: 반죽 양에 따라 크기가 바뀌는 반죽
- `topping-buchu.svg`, `topping-kimchi.svg`, `topping-haemul.svg`: 주문별 재료
- `order-board.svg`: 팬 밖에 주문명과 인내심을 표시하는 주문판
