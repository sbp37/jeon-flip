# 전 뒤집기

모바일 웹 1탭 타이밍 미니게임. 후라이팬 위 전이 노릇노릇하게 익는 순간을 노려 탭해서 뒤집는다. 60초 안에 최대한 많은 전을 성공시키는 게임.

## 실행

정적 파일만으로 동작. 로컬에서 보려면:

```bash
python3 -m http.server 8000
# http://localhost:8000
```

## 규칙

- 반죽이 자동으로 부어지고 서서히 익는다
- 화면 아무 데나 또는 큰 「뒤집기!」 버튼을 탭
  - 너무 빠름 → 덜 익음 (실패)
  - 적절한 타이밍 → 노릇노릇 성공 (+점수, 콤보)
  - 너무 늦음 → 탐 (실패)
- 성공하면 바로 다음 전이 시작된다

## 전 종류

| 종류 | 특성 |
|---|---|
| 부추전 | 기본. 익는 속도 보통, 판정 넓음 |
| 김치전 | 색 변화가 헷갈림. '지금이야!' 힌트 없음 |
| 해물전 | 익는 속도 느림, 성공 구간 좁음 |

사운드는 WebAudio로 합성(지글지글/뒤집기/성공·실패). 첫 탭 이후 재생됨.
